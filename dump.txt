history of programming: machine language is tedious not scalable and prone to errors. next came assembly language which was slightly better but still tedious and not scalable, it was tightly coupled to hardware. then came procederal language it introduces fucntions, blocks etc it told do then and do this but it lacked real world mmodelling. data security was also not there and it was not scalable and not reusable. 

a object has two things charactersticks and behaviour. for example a car has charactersticks like engine wheel model brand etc and it has behaviour like start stop gearshift accelerate brake etc. so we make a class for car and this class acts like a blueprint to make a new car.

 there are 4 major principles of oop whcih are: abstraction, polymorphism, encapsulation and inheritence. 

 abstraction provides an interface for a perticular problem or use case as an object may have complex implementation but we just need to know what methods to use.
  for example we just need to know how to start the car and not how it works.

  encapsulation is nothing but wrapping of data and methods that operate on the data in a single unit called a class. 
  for example we wrap the data of the car in a class and the methods that operate on the data in the same class.

  polymorphism is nothing but the ability of an object to take many forms.
  for example we can have a method add which can add two numbers or two strings.

  inheritence is nothing but the ability of a class to inherit the properties of another class. 
  for example a car can inherit the properties of a vehicle.
